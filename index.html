AI assistant

The Assistant and the Workout coach use a free Google Gemini key.

  1. Open aistudio.google.com/app/apikey and log in with a Google account.
  2. Tap Create API key and copy it (it starts with AIza or AQ.).
  3. Paste it here and tap Save.

The key is free for personal use. It’s saved on your devices and in your own cloud, and only sent to Google’s Gemini.

Cloud sync
Cloud sync is offLog in in Workout → You to back up everything and use Life Hub on more devices.
Your Firebase database rules only allow workout data. In the Firebase console → Firestore Database → Rules, replace the rules with: 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}

Syncs everything in Life Hub per item, so changes on two devices both survive. Your workouts sync through the Workout app. Receipt files and clothing photos stay on this device: they’re in the backup file.
